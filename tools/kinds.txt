# Kinds ("fake types"): what integer parameters, results and record fields mean for the game (unit ID, hand index,
# X coordinate, ...). Each kind is declared as a hidden alias type in Types.script; members get "@kind" doc tags.
# Read by generate_stubs.py. Lines starting with "#" are comments.
#
#   kind <Alias>: <underlying>; <policy>; <label>[; prefer <EnumType>]; <description>
#       declares an alias; policy = id | index | coordinate | legacy-id | count
#   param <name> [<name>...] = <Alias>
#       integer parameters / record fields with one of these names get "@kind <name> <kind>"; a name may be qualified
#       with the member (Actions.GiveUnit.aType) or the record (TKMDefencePositionInfo.GroupID)
#   return <Page.Member> = <Alias>
#       the integer (or integer array) result of that member gets "@kind <kind>"
#   return-comment <text> = <Alias>
#       integer results whose wiki return comment equals <text> (case-insensitive) get the alias

kind TKMUnitID: Integer; id; unit ID; Identifier of a unit (States.UnitAt, Actions.GiveUnitEx, event parameters). -1 = none.
kind TKMHouseID: Integer; id; house ID; Identifier of a house (States.HouseAt, Actions.GiveHouseEx, event parameters). -1 = none.
kind TKMGroupID: Integer; id; group ID; Identifier of a group of warriors (States.GroupAt, Actions.GiveGroupEx). -1 = none.
kind TKMHandIndex: Integer; index; hand index; Index of a hand (player), 0-based. -1 = none / all players, depending on the function.
kind TKMCoordX: Integer; coordinate; X coordinate; X (column) coordinate of a map tile.
kind TKMCoordY: Integer; coordinate; Y coordinate; Y (row) coordinate of a map tile.
kind TKMUnitTypeID: Integer; legacy-id; unit type id; prefer TKMUnitType; Integer unit type of the old API. Newer functions take TKMUnitType instead.
kind TKMHouseTypeID: Integer; legacy-id; house type id; prefer TKMHouseType; Integer house type of the old API. Newer functions take TKMHouseType instead.
kind TKMWareTypeID: Integer; legacy-id; ware type id; prefer TKMWareType; Integer ware type of the old API. Newer functions take TKMWareType instead.
kind TKMGroupTypeID: Integer; legacy-id; group type id; prefer TKMGroupType; Integer group type of the old API (0 melee, 1 anti-horse, 2 ranged, 3 mounted). Newer functions take TKMGroupType instead.
kind TKMDirectionID: Integer; legacy-id; direction id; prefer TKMDirection; Integer direction of the old API (0..7). Newer functions take TKMDirection instead.
kind TKMTicks: Integer; count; tick count; Number of game ticks (10 per second at normal speed): game time, delays, hunger levels.
