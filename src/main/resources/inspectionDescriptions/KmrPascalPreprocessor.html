Reports problems found while following the compilation unit the file belongs to: an included file that cannot be found, recursive includes, a file included twice with active content (declarations would be duplicated), {$IFDEF}/{$IFNDEF} without {$ENDIF}, and {$ELSE}/{$ENDIF} without an opening conditional.

Also reports {$EVENT} directives that name an unknown event, a procedure the unit does not declare (a quick fix creates it with the event's signature), or a procedure that already handles an event: the game keeps one handler list per event and refuses a procedure that is in it already, which includes the default handler it registers itself ({$EVENT evtTick:OnTick}).
