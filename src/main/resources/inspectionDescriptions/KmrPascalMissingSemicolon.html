Reports a statement that is not followed by ;, with a fix that inserts it. PascalScript compiles such code: semicolons between the statements of a block are optional for it, as is the one before end, until or the else of a case. Writing them anyway keeps the code readable and avoids surprises when statements are moved around, so this is a readability warning. Nothing is reported where a semicolon is not allowed (a then branch followed by else). A single statement after then, else or do must be followed by ;, else or end; that is enforced by the game and reported as a syntax error.
