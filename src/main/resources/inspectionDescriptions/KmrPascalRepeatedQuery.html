Reports a States query evaluated again with the same arguments while its result cannot have changed.

A script runs to completion within one game tick, and only Actions change the game. So between two calls of States.UnitOwner(U) with no Actions call, no call of a routine of the script (which might call Actions) and no change of U in between, the second call returns the same value. Every States call crosses into the game engine, so the quick fix stores the first result in a local variable and uses that instead.
