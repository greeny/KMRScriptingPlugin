Reports uses of declarations marked @deprecated in their doc comment, and handlers of deprecated events (a procedure with the event's name, or a {$EVENT} directive naming the event). The API stubs use this to steer scripts from integer-id based functions and events to their type-based successors (for example GiveUnit to GiveUnitEx, OnUnitAfterDied to OnUnitAfterDiedEx).

Where the migration is exact, the quick fix rewrites the code: integer ids given as numbers or named constants become the enum members the Ex variant takes (14 becomes utMilitia, [0, 1] becomes [gtMelee, gtAntiHorse]), a result compared with or switched on constants is converted the same way, and an event handler is renamed (or its directive re-pointed) with its id parameters typed as the enum and every use of them converted. Calls passing variables, and handlers that store or compute with an id parameter, are left alone.
