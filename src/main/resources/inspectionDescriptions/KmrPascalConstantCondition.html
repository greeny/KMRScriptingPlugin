Reports conditions whose outcome follows from what happened before them in the same routine.

The plugin follows the values of variables, record fields and constant-indexed array elements through a routine, and what conditions say about them: inside if A = True then, A is known to be True, so a nested if A = False then can never run; after if not Ok then exit;, Ok is True; after Found := False;, if Found then is always false. Hover a variable to see the value known at that point.

States queries are followed as well: a script runs within one game tick and only Actions can change the game, so States.UnitOwner(U) = 3 is still true where it was true before, as long as no Actions member was called and U was not changed.

Conditions that are constant by themselves (if DEBUG then, while True do) are not reported.
